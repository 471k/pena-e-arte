Limitations to flag

  • Only Premium has a seeded yearly PlanPrice row. The other four tiers carry YearlyDiscountPercent = 17, but that's the "Save 17%" marketing figure only — there's no purchasable yearly price for them yet.
  • Every Max* field is non-null on all five tiers — none is truly unlimited. Pro's caps are explicitly a soft ceiling (per seeder comment) to protect shared Twilio/Hangfire/DB load, not a real unlimited tier.
  • MaxLocations is not enforced today: PlanLimitService always reports usage of 1 for the Locations quota because Studio is still single-location. That column is aspirational until multi-location ships.
  • Storage limit is enforced as MaxStorageGb × 1024³ bytes against Studio.StorageUsageBytes — a stored counter, not a live recount.
  • These five rows are not issuer-editable through PlanManagementPage — they're reconciled from source control on every app start. To change a value, edit the CoreTier array in DataSeeder.cs. Issuers get new tiers by cloning a new Plan row, not editing a core one.
